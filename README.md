# واژه‌یار

تمرین واژگان انگلیسی و فارسی برای دسکتاپ، با Next.js App Router، TypeScript و Tailwind CSS.

```powershell
npm install
npm run dev
```

آدرس [localhost:3000](http://localhost:3000) را باز کن. برای ساخت نسخهٔ تولید از `npm run build` و برای اجرای آن از `npm start` استفاده کن.

از منوی مجموعهٔ فعال می‌توانی واژگان PDF و مجموعه‌های آمادهٔ برنامه‌نویسی، انگلیسی روزمره، چت، محیط کار و جلسه، افعال عبارتی و مطالعه را انتخاب کنی. برای افزودن مجموعهٔ تازه، یک نام انتخاب کن و فایل UTF-8 با پسوند TXT، CSV یا TSV را وارد کن، یا واژه‌ها را با این قالب بچسبان.

```text
curious | کنجکاو
steady | ثابت، پایدار
look up | جست‌وجو کردن
```

علامت «یاد گرفتم» در کتابخانه دستی قابل تغییر است. در تمرین‌ها، پاسخ درست در موعد مرور فاصلهٔ مرور بعدی را افزایش می‌دهد. در صورت اشتباه، واژه وارد فهرست اشتباه‌ها می‌شود و بعد از ده دقیقه دوباره به صف مرور می‌آید. علامت یادگیری، مجموعه‌های واردشده و تم در localStorage همان مرورگر و همان آدرس ذخیره می‌شوند. دیکته و تلفظ از صدای انگلیسی مرورگر استفاده می‌کنند.
